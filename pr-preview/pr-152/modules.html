peta.core.vulns.merge_vulnerabilities(existing, extra)[source]#

Merge two vulnerability lists, deduping by identity.

Two vulnerabilities are the same if they share their id or any overlapping alias. When a candidate’s identity bridges several existing entries (e.g. it carries aliases of two otherwise-unrelated entries), ALL of them are folded into one cumulative entry rather than merging into only the first match. The result prefers a non-None severity and unions aliases and fixed_in.

Parameters:

  • existing¶ – Vulnerabilities already known (e.g. from PyPI).

  • extra¶ – Additional vulnerabilities to merge in (e.g. from OSV).

  • existing (list[Vulnerability])

  • extra (list[Vulnerability])

Returns:

A deduped list, with existing entries first, in order.

Return type:

list[Vulnerability]
