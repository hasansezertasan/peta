Usage
=====

As a library
------------

To use ``peta`` in a project:

.. code-block:: python

   import peta

As a command-line tool
----------------------

To use ``peta`` as a command-line tool:

.. code-block:: sh

   peta version
   peta info

As a TUI
--------

To launch the terminal user interface:

.. code-block:: sh

   peta-tui
